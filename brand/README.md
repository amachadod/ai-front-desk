# Brand

A small, restrained brand for AI Front Desk and the suite of tools it routes to.

- **Name:** AI Front Desk (working name; change it in `hub.config.json` and the README title).
- **Logo:** [`logo.svg`](logo.svg): a door frame with one path splitting into three routes, the hub's job in one picture. It uses `currentColor` for the frame, so it works on light and dark backgrounds.
- **Palette:** ink, paper and one indigo accent. Each tool in the suite keeps its own accent (Minuta red, Posta yellow, Threadline teal, Signalpost orange, Plano cobalt, AdsDetective wine), used by the hub only as small markers so the suite reads as one family.
- **Type:** Fraunces for headings, Public Sans for text, IBM Plex Mono for data (Google Fonts, with system fallbacks).
- **Tokens:** [`tokens.css`](tokens.css), light and dark.
